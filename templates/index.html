Tentang Proyek SCEM

SCEM (Smart Classroom Environment Monitor) dikembangkan untuk memantau suhu dan kelembapan ruang kelas menggunakan mikroprosesor ESP32, sensor DHT22, protokol MQTT Cloud, serta dasbor interaktif Python Flask.

Fitur Unggulan:
  • Pemantauan grafik real-time dan interaktif (zoom & pan).
  • Peringatan otomatis via WhatsApp jika suhu melampaui 29.0°C.
  • Alarm buzzer lokal di perangkat ESP32.
  • Mode tampilan terang dan gelap yang dapat dipilih pengguna.
Pertanyaan Umum (FAQ)

Sistem secara otomatis membunyikan buzzer peringatan pada ESP32 dan mengirimkan pesan WhatsApp darurat ke nomor admin.

Sensor memperbarui telemetry data via MQTT broker setiap 10 detik, dan grafik dasbor menyegarkan tampilan setiap 3 detik.

ESP32 memiliki buffer retry otomatis yang akan terus berusaha menyambungkan ulang ke MQTT Broker. Data lokal disimpan sementara hingga koneksi pulih.
